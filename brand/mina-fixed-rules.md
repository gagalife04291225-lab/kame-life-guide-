# Mina Fixed Rules — FIXED CORE

> **ミナ本人の Single Source of Truth。**
> このファイルには **人物ID だけ**を書く。商品名・特定の部屋・特定の動画・特定のCUT・特定の服・特定の髪型は書かない。
> 可変モジュールと生成手順は [`mina-image-rules.md`](./mina-image-rules.md)。SHOT PLAN のひな型は [`mina-shot-template.md`](./mina-shot-template.md)。

## 1. 目的と位置づけ

ミナは KAME LIFE GUIDE repo で管理する固定ブランドキャラクターであり、**商品カテゴリ・媒体・出力形式を問わず**すべての商品紹介・SNS投稿・広告素材で使う人物基準である。

このファイルは「ミナがどんな人物か」と「同一人物として維持するための不変条件」の正本である。

**商品が変わっても、媒体が変わっても、このファイルは変更しない。**
用途ごとに変わるものは可変モジュール側にあり、そちらを差し替えて使う。

### 「ミナを固定する」の意味

**固定するのは人物IDであって、ポーズ・顔向き・服・背景・商品ではない。**

「ミナを固定する」とは **同一人物性を維持すること**であり、次を繰り返すことではない。

- 同じ顔角度
- 同じ表情
- 同じポーズ
- 同じ服
- 同じ背景
- 同じカメラ位置

同じ人物が、違う場面で、違う角度から写っている状態が正しい。
毎回同じ角度・同じ距離・同じ笑顔で商品だけ差し替えた画像は、**同一人物性を守っていても不合格**とする。

### 責務の境界

| 層 | 中身 | 置き場所 |
|---|------|---------|
| **FIXED CORE** | 人物ID・年齢感・顔骨格・一重・肌質・髪色の基本・体型傾向・ナチュラルメイク・親しみやすさ・清潔感・自然体・AI美女化禁止・過剰加工禁止・`MINA_MASTER` 運用・別人化禁止 | **本ファイル** |
| **VARIABLE MODULES** | SCENE（場面）／ WARDROBE（服装）／ HAIR（髪型）／ EXPRESSION（表情） | [`mina-image-rules.md`](./mina-image-rules.md) |
| **PRODUCT INTERACTION** | 商品ごとの正しい操作・関わり方 | [`mina-image-rules.md`](./mina-image-rules.md) ＋ 各商品案件側 |
| **CAMERA / GAZE / CONTENT MODE** | 顔向き・距離・位置・視線整合・用途モード | [`mina-image-rules.md`](./mina-image-rules.md) |
| **SHOT PLAN** | カット単位の設計。ひな型は共通、中身は案件ごと | [`mina-shot-template.md`](./mina-shot-template.md) ／ 各商品案件側 |
| **商品固有データ** | 商品名・型番・実寸・URL・価格・台本 | **`brand/` に置かない。** 各商品案件側（`qc-evidence/<案件>/` 等） |

## 2. MINA_MASTER — 人物固定の基準

- **文章の人物設定だけでは顔は固定できない。**
- Owner が承認した1枚の画像を `MINA_MASTER` として扱い、以後の生成は必ずその画像を人物参照に使う。
- 新しいチャット／新しい生成セッションでは、`MINA_MASTER` を添付・参照できない状態で「ミナ」とだけ指定してゼロから生成しない。
- 商品を持たせる場合も、`MINA_MASTER` を元にした編集または参照生成を原則とする。
- 派生画像は人物同一性の補助参照には使えるが、正本は `MINA_MASTER` 1枚とする。派生を何世代も連鎖参照しない。
- 人物がドリフトしたと判断したら、派生画像をたどらず `MINA_MASTER` へ戻る。
- **現在のスコープでは MASTER 画像バイナリ自体は repo に保存しない。** 新しいチャットでは Owner 承認済み MASTER 画像を添付すること。画像が無い場合は生成を開始せず、MASTER 提示を求める。
- **MASTER を参照する目的は人物同一性の維持であり、MASTER と同じ顔角度・同じ構図をコピーすることではない。** MASTER の顔角度をそのまま流用した画像を並べると、同一人物性は保てても「同角度量産」になる。

## 3. FIXED CORE — 固定する人物設定

- 日本人女性
- 年齢感は30代
- 親しみやすく、清潔感があり、やさしい印象
- 親近感のある自然体
- 整いすぎない自然な顔立ち
- 量産型の「AI美女」風にしない
- 若すぎる印象にしない
- 卵型寄りのやさしい顔（顔の基本骨格）
- 一重
- 細身（体型傾向）
- ダークブラウン〜黒に見える自然な暗髪（髪色の基本）
- ナチュラルメイク
- 顔のテカリを抑え、自然な肌質を残す
- 毎回、`MINA_MASTER` と同一人物に見えることを最優先する

服装・髪型・表情・場面は FIXED CORE に含まれない。**可変モジュール**として扱う（§1 責務の境界）。

## 4. 変えてはいけない要素

- 年齢感の大幅変更・若返り
- 別人化
- 顔立ちの再設計
- 二重化など目元の大幅変更
- 量産型AI美女化、アイドル化
- 過度な美肌補正、陶器肌、強い顔面ハイライト
- 極端な体型変更
- 髪色の大幅変更
- キャラクター性が変わる服装（可変モジュール内でも、これを超える変更はしない）
- `MINA_MASTER` を無視したテキストのみの再生成

## 5. 人物に関する生成禁止事項

- 他のAI美女アカウント、実在人物、既存キャラクターの模倣
- テンプレ顔への寄せ直し
- MASTER なしでの量産
- 「同じ設定文だから同一人物」とみなすこと
- 毛髪に水滴・フケのように見える白い粒、白い斑点、不要な反射物を生成すること
- AI感の強い過剰な左右対称、過剰なスタジオ照明、過度な肌光沢

商品・背景・構図に関する禁止事項は [`mina-image-rules.md`](./mina-image-rules.md)「ANTI-AI PATTERN」にある。ここへ重複記載しない。

## 6. 変更履歴（旧ルールとの衝突を隠さないために残す）

### v1 → v2（2026-09-10）

旧 `mina-image-rules.md` の「お団子ヘア固定／髪型変更禁止」「アパートのリビング固定」を Owner 指示で更新した。

- **髪型**: 完全固定 → 同一人物性を保つ範囲の小変化を許可
- **背景**: リビング1種類固定 → 統一された簡素な室内世界観
- **目元**: 一重を固定条件として追加
- **肌**: 顔のテカリを抑える条件を追加
- **人物固定方法**: 設定文中心 → `MINA_MASTER` 実画像参照を必須化
- **「固定」の定義**: 固定するのは人物であって構図ではない、と明文化

### v2 → v3（2026-09-10・ブランドキャラクター基盤化）

特定商品・特定場面・特定台本に寄っていた構造を、**FIXED CORE ＋ 可変モジュール**へ分離した。

- **本ファイルを人物ID専用にした。** 背景（SCENE）・服装（WARDROBE）・髪型（HAIR）・表情（EXPRESSION）の内容を可変モジュールとして [`mina-image-rules.md`](./mina-image-rules.md) へ**移設**した（複製ではない）。
- §1 に責務の境界表を追加し、どの情報がどのファイルに属するかを固定した。
- 商品固有データ（商品名・型番・実寸・URL・価格・台本）を `brand/` に置かない方針を明記した。

**商品カテゴリ専用の人物ルールは作らない。** ガジェット用ミナ・美容用ミナ等を分岐させない。

## 7. 優先順位

ミナ関連の人物固定で記述が競合した場合は、次の順で扱う。

1. Owner の最新の明示指示
2. 本ファイル `brand/mina-fixed-rules.md`
3. `brand/mina-image-rules.md` の可変モジュールと生成手順
4. `brand/mina-shot-template.md` のひな型
5. 過去のプロンプト・過去の派生画像

人物設定を変更する場合は、この正本だけを更新し、同じ固定情報を別ファイルへコピーしない。
