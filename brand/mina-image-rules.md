# Mina Image Rules — VARIABLE MODULES / 生成運用

> **商品・カテゴリ・媒体を問わず使う、画像・動画のビジュアル生成運用。**
> 人物IDの正本は [`mina-fixed-rules.md`](./mina-fixed-rules.md)。人物設定をこのファイルへ重複記載しない。
> SHOT PLAN のひな型は [`mina-shot-template.md`](./mina-shot-template.md)。
>
> **このファイルに商品名・型番・実寸・URL・価格・台本を書かない。** それらは各商品案件側（`qc-evidence/<案件>/` 等）に置く。

対応する用途: TikTok / Instagram Reels / Instagram フィード / YouTube Shorts / 楽天アフィリエイト / Amazon 商品紹介 / TikTok Shop / プロフィール画像 / サムネイル / 商品比較 / ランキング。
対応する商品カテゴリ: ガジェット / キッチン用品 / 収納 / 掃除 / 美容 / ファッション小物 / 食品 / 旅行グッズ / デスク用品 ほか。

**特定カテゴリ専用の人物ルールは作らない。** 差し替えるのは以下のモジュールだけである。

---

## 生成前チェック（新しいチャットでの必須手順）

1. [`mina-fixed-rules.md`](./mina-fixed-rules.md) を最新 main から読む。
2. 本ファイルを最新 main から読む。
3. `MINA_MASTER` の実画像が現在のチャット／生成セッションで参照可能か確認する。
4. 実商品の画像（一次商品画像）を確認する。
5. 実商品の仕様・実寸・実際の操作方法を確認する。
6. 今回の CONTENT MODE と可変モジュール（SCENE / WARDROBE / HAIR / EXPRESSION）を決める。
7. [`mina-shot-template.md`](./mina-shot-template.md) を使って SHOT PLAN を先に作る。
8. SHOT PLAN 上で、同じ角度・同じ構図の連続が無いか確認する。
9. 各カットの視線先と行動対象を確定する。
10. 生成する。
11. 生成後QC を1枚ずつ行う。

`MINA_MASTER` が無ければ、名前・文章設定だけで生成を開始しない。Owner に MASTER 画像の提示を求める。
**MASTER または実商品画像が無い状態で、実在商品を推測生成しない。**

## VARIABLE MODULES

用途ごとに差し替える層。ここを変えるだけで新しい商品・新しい媒体に対応できるようにする。
**モジュールを変えても [`mina-fixed-rules.md`](./mina-fixed-rules.md) は変更しない。**

### SCENE（場面）

用途に応じて変更可。

キッチン / 洗面所 / リビング / 寝室 / デスク / 玄関 / 窓辺 / カフェ風室内 / 旅行準備 / クローゼット周辺 / 無地背景

維持する世界観（場面を変えても崩さない）:
- 日本の自然な生活空間であること
- ベージュ・クリーム・ナチュラルウッド中心の落ち着いた色味
- 過剰におしゃれな部屋・AIモデルルーム風にしない
- 小物を増やしすぎない。観葉植物を毎回置かない
- 過剰な被写界深度・強いボケを使わない
- 柔らかい自然光または控えめな暖色光
- 商品より背景が目立たない

運用:
- **毎回同じ背景にしない。** 連続する投稿で同じ場所が続いたら次は別の場所へ移す。
- 毎回同じ大型家電・同じ植物・同じ棚をテンプレ配置しない。
- 背景を回すのは**投稿単位**であり、1本の動画のカット単位ではない（VIDEO CONTINUITY 参照）。

### WARDROBE（服装）

用途に応じて変更可。

白／ベージュ系ニット / シンプルTシャツ / カーディガン / シャツ / 部屋着寄り / 外出用カジュアル

禁止:
- 毎回同じ服
- 派手すぎる衣装
- キャラクター性が変わる服装
- 不自然な露出に依存した構図

1本の動画の中では continuity を維持する。

### HAIR（髪型）

投稿間では小変化可。

低いお団子 / 低いポニーテール / ダウン / 耳かけ / ハーフアップ

- 髪型を変えても、髪色・生え際・顔周辺の印象を大きく変えて別人化させない。
- **1本の動画の途中で理由なく変えない。** 動画単位で統一し、変更は別投稿で行う。

### EXPRESSION（表情）

用途に応じて変える。

ニュートラル / 軽い笑顔 / 興味 / 集中 / 驚き / 納得 / 結果を確認する表情

- **毎回同じ笑顔は禁止。** 1つの表情に固定しない。
- 表情はその瞬間の行動から決める。行動と無関係な笑顔を貼らない。

## PRODUCT INTERACTION（商品インタラクション）

商品ごとに「正しい使い方」を読み取り、ミナの動作をその商品に合わせる。
**人物ルール側にも本ファイルにも、特定商品の動作を書かない。**

関わり方の母集合:

持つ / 置く / 押す / 引く / 開ける / 閉じる / 差し込む / 装着する / 収納する / 掃除する / 食べる / 飲む / 身につける / スマホへ接続する / カバンから出す / 実演結果を見る

原則:
- **商品画像・仕様・実寸・操作方法を確認してから動作を決める。**
- 生成AIが勝手に別の使用方法を作らない。
- 案件側に台本がある場合は台本の動作が優先する。
- **「商品を片手で持ってカメラを見る」だけを連続させない。**

---

## GAZE / ACTION SYSTEM（商品非依存の恒久ルール）

顔の向き・眼球方向・手の動作・商品位置を、バラバラの属性ではなく**1つの行動として設計する。**

### 視線は行動対象と一致させる

| 場面 | 視線の向き先 |
|------|------------|
| 操作中 | 操作点 |
| 結果確認 | 結果 |
| 開封中 | 手元 |
| 装着中 | 装着箇所 |
| 食べる | 食品 |
| スマホ操作 | 画面 |
| 鏡使用 | 鏡 |
| 商品紹介 | **カメラ目線可** |
| CTA | **カメラ目線可** |

### カメラ目線の使用範囲

カメラ目線を使ってよいのは **「商品紹介」「CTA」の2場面だけ**とする。
作業中・操作中のカットでカメラ目線にしない。

### 禁止

- 手元作業中に無関係な場所を見る
- 顔と眼球の方向が不一致
- 全カットカメラ目線
- 毎回同じ左下を見る
- 商品とは逆方向を見る
- 視線の先に何も無い

### 顔向きも動作に合わせる

**目だけを動かさない。**
商品が右下にあるなら頭部も自然に右下へ少し向く。手元を覗き込むなら**首・顎・顔面方向・眼球**が自然につながること。
「首だけ正面 ＋ 眼球だけ真横」は禁止。

### 目視QC

生成後、**両目の視線方向を延長したとき、実際の行動対象へ向いているか**を必ず目視で確認する。
「だいたい合っている」で通さない。延長線が対象を外れていれば再生成する。

---

## CAMERA SYSTEM

商品ごとに自由に組み合わせる。**固定人物だからといって同じカメラ構図を繰り返さない。**

| 軸 | 母集合 |
|----|--------|
| 顔向き | 正面 / 左3/4 / 右3/4 / 左横顔 / 右横顔 / 後方3/4 / 顔なし手元 |
| 距離 | クローズアップ / バストアップ / 腰上 / 上半身 / 手元 / 商品アップ / 俯瞰 / 肩越し |
| 位置 | 正面 / 左 / 右 / 斜め / 俯瞰 / 鏡越し |

運用:
- 複数枚を作る場合、顔向きは**3種類以上**に分散させる。
- 母集合の並び順に機械的に割り当てない。各カットの行動内容から必要な構図を決め、結果として分散していることを SHOT PLAN で確認する。
- 全カットに顔を入れる必要はない。**操作の証拠カットでは手元・商品アップを主役にしてよい。**

---

## CONTENT MODE

用途モード。1つの投稿で自由に組み合わせる。

| MODE | 目的 | 主役 | カメラ目線 |
|------|------|------|-----------|
| `PRODUCT_HOOK` | 商品を持って最初の1秒で視線を止める | 顔＋商品 | 可 |
| `PRODUCT_DEMO` | 商品操作を見せる | 手元優先可 | 不可 |
| `RESULT` | 使用結果を見せる | 結果・商品 | 不可 |
| `REACTION` | 結果を見た自然な反応 | 顔 | 原則不可（結果を見る） |
| `CTA` | カメラへ視線を戻す | 顔＋商品 | 可 |
| `LIFESTYLE` | 商品を生活シーン内に自然に置く | 場面全体 | 不可 |
| `PROFILE` | プロフィール画像。商品なしでも可 | 顔 | 可 |
| `THUMBNAIL` | 商品と顔を同時に明確に見せる | 顔＋商品 | 可 |
| `STORY` | 複数カットで小さな物語を作る | カットごと | カットによる |

組み合わせ例（順序は固定しない）:
- 短尺実演: `PRODUCT_HOOK` → `PRODUCT_DEMO` → `RESULT` → `CTA`
- 生活提案: `LIFESTYLE` → `PRODUCT_DEMO` → `REACTION`
- 静止画のみ: `THUMBNAIL` 単体、`PROFILE` 単体

---

## PRODUCT SCALE

**商品実寸が確認できる場合、人物の手・顔・身体との縮尺を現実に合わせ、カット間で変えない。**

禁止:
- 実物より大きく／小さく描く
- 手との縮尺がカットごとに変わる

**特定商品の寸法をこのファイルへ保存しない。** 実寸の正本は各商品案件側（商品レコード）にある。
実寸が確認できない場合は、確認できるまで縮尺を推測で確定しない。確認できないまま生成するなら「片手で扱えるか否か」程度の粗い前提に留め、その前提を SHOT PLAN に明記する。

## VIDEO CONTINUITY

1本の動画内では次を**維持する**。

- 同一人物
- 服装
- 髪型
- 商品個体・商品色・商品サイズ
- 基本背景（同一空間・家具配置）
- 基本照明（方向と色味）

1本の動画内でも次は**変える**。

- カメラ角度
- 顔向き
- 距離
- 視線
- 主役（顔／商品／手元）

原則:

> **変えるのはカメラと身体。壊してはいけないのは人物と世界。**

---

## ANTI-AI PATTERN

ミナの横展開すべてに共通する禁止。

- 毎回同じ3/4顔
- 毎回同じ笑顔
- 毎回同じ服
- 毎回同じ背景
- 毎回商品を胸元で持つ
- 毎回カメラ目線
- 毎回同じ手の高さ
- 商品だけ差し替えた量産画像
- AIモデルルーム背景
- 過剰なボケ
- スタジオ的均質照明
- 陶器肌
- 不自然な左右対称
- 髪の白粒
- 不自然な手指

**同一人物性を維持しながら、投稿ごとの画面印象は変える。**

自然な瞬間を優先する: 作業に集中している / 少し考えている / 商品を確認している / 軽く笑う / 無表情寄り / 結果を見て表情が変わる。

---

## 量産時のルール

- 何枚作る場合も、各生成を `MINA_MASTER` から派生させる。
- 派生画像だけを連鎖参照して世代を重ねない。顔のドリフトを防ぐため定期的に MASTER へ戻す。
- 変える要素を1回の生成で増やしすぎない。
- 生成後に MASTER と並べて目視確認し、別人に見える場合は不採用。

---

## 生成後QC

1枚ごとに確認する。**1つでも重大 FAIL があれば採用せず再生成する。**

**IDENTITY** — `MINA_MASTER` と同一人物に見えるか / 年齢感・一重・肌・髪色が維持されているか / 顔のテカリが強くなっていないか

**SHOT** — 前カットと同角度の焼き直しになっていないか / カメラ距離が単調になっていないか

**GAZE** — 視線が行動対象へ向いているか（両目の視線延長線で確認）/ 顔向きと眼球方向が一致しているか

**ACTION** — 手が行っている作業と顔・視線が一致しているか / 商品の使い方が実物と一致しているか

**PRODUCT** — 大きさが正しいか / 色・形・ボタン・端子・ロゴを勝手に変更していないか

**HANDS** — 指の本数 / 関節の向き / 商品の握り方 / 接触位置

**MODULES** — SCENE・WARDROBE・HAIR・EXPRESSION が今回の指定どおりか / 前回の投稿と同じ組み合わせの使い回しになっていないか

**CONTINUITY**（動画の場合）— 同一動画内で人物・服・髪・商品個体・背景・照明が保たれているか

**ARTIFACT** — 髪の白粒 / 不自然な肌 / 謎の文字 / 商品形状の破綻

**OUTPUT** — 用途の縦横比を満たしているか / 顔・商品・字幕の安全領域を確保できるか

---

## 商品持ち画像の基本フロー

1. `MINA_MASTER` を人物参照にする。
2. 実商品の正しい商品画像を別参照にする。
3. 指示は「人物を作り直す」ではなく、**人物IDを維持したまま商品を自然に扱わせる編集**として行う。
4. 商品ロゴ・色・形状・ボタン・端子等を推測で変えない。
5. 背景変更が不要なら元画像の背景をできるだけ維持する。変える場合も SCENE モジュールの範囲だけにする。

---

## 出力の基本

- 縦型 9:16 を基本とする（TikTok / Reels / Shorts）。フィード用の 1:1・4:5、サムネイル用の 16:9 は用途に応じて選ぶ。
- ミナを視線停止の主役、商品を販売対象として明確に分ける。
- プレースホルダー容器を実商品として扱わない。
- 商品広告では必要な PR 表示・AI生成コンテンツ表示を別工程で適切に行う。
