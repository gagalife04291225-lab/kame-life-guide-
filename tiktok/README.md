## 2本目の作り方
`make_video.py` の `SCENES`（テロップ・秒数）を書き換えて実行するだけ。
デザイン（色・フォント・配置・セーフエリア）は共通化済みのため変更不要。

```bash
pip install Pillow imageio-ffmpeg    # 初回のみ
python3 tiktok/make_video.py
```

## 自動で検証される項目（実行時に停止するので目視不要）
- テロップの文字切れ（最大幅864px超過で停止）
- セーフエリア違反（TikTok UI領域への侵入で停止）
- コントラスト比（WCAG AA 4.5:1）
- 総尺・タイムラインの連続性

## 共通仕様（全動画で固定）
- 1080x1920 / 30fps / 40秒前後
- ブランドカラー: #0d1f1a（背景）/ #f4efe2（本文）/ #d4a96a（強調）
- 画面上部に「カメの誤解 ｜ #N」を常時表示
- 構成: フック → 否定 → 事実 → 図解 → 結論 → CTA
- CTA文言は**3本とも変えない**（導線の効果を測るため）

## 毎回変えるもの
- フック（冒頭3秒の言い回し）← 第1優先
- 題材
