# フォント

短尺動画のテロップ用。**サイト本体と同じ書体族**（Noto Sans JP / Noto Serif JP）を使い、
Web とブランドを揃える。

| ファイル | 用途 |
|---------|------|
| NotoSansJP-Black.otf  | テロップ本体（極太） |
| NotoSansJP-Bold.otf   | バッジ・補助 |
| NotoSerifJP-Black.otf | CTA（サイトの明朝見出しに合わせる） |

導入理由: この環境の日本語フォントは IPAゴシック Regular のみで、
**太字が1つも無かった**（`fc-list :lang=ja` で確認）。本文用の細いウェイトを
見出しに使っていたため、テロップが細く平板に見えていた。

出典: https://github.com/notofonts/noto-cjk （SIL Open Font License 1.1）
