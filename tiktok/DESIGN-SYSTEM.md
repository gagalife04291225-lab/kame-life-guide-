# KAME LIFE GUIDE — TikTok Design System v1.0

> 根拠: `tiktok/research/RESEARCH-REPORT.md`（記号 A1〜I3 / Y1〜Y14 / Z1〜Z10 はそこの通し番号）
> 検証: `tiktok/research/analyze_video.py`（全フレーム走査で自動測定）
> 適用: `tiktok/make_video3.py` は本DSの数値要件を**制作前にチェックし、違反したら制作を中止する**。

判断順序（不変・上位が常に勝つ）: **正確性 ＞ 信頼 ＞ ブランド ＞ 品質 ＞ 再生数 ＞ 利益**

---

## 1. 映像テンプレート（構成）

固定の9ブロック。番号はシリーズ全話で共通にする。

| # | ブロック | 目安 | 役割 | 根拠 |
|---|---------|------|------|------|
| 1 | フック前半 | 0.0-1.0s | 何の動画かを画で示す＋テロップ1行目 | Y1 |
| 2 | フック後半 | 1.0-1.9s | 同じ被写体へ寄る（ハードカット）＋問いを完成 | Y2 |
| 3 | 否定 | 〜3.3s | 「間違いです」= Contrarian Strike | A8 |
| 4 | 実演 | 〜6.3s | 誤解を画で見せて✕で否定 | Y3 |
| 5 | 正体 | 〜15.1s | 事実の視覚的証明（本編の核・保存ポイント） | B2 |
| 6 | リフック | 40〜50%地点 | 別の問いで引き直す | Y8 |
| 7 | 深掘り | 〜27s | 証明の続き（内部構造・危険性） | — |
| 8 | 結論＋例外 | 〜31s | 冒頭の問いを回収し、**例外を隠さず出す** | ブランド |
| 9 | コメント→保存→CTA | 〜41s | 問い → まとめ → プロフィール | Y9/Y10/Y12 |

**尺: 38〜45秒**（根拠 Y13 / F1・F3・F4）。60秒超は本DSでは作らない。

## 2. 編集ルール（数値・自動検証あり）

| 指標 | 基準 | 根拠 | v3実測 |
|------|------|------|--------|
| 尺 | 38-45秒 | Y13 | **41.4秒** ○ |
| カット数 / 10秒 | **≥ 2.5** | D3 | **6.04** ○ |
| カット長 中央値 | **≤ 2.0秒** | D1/Y5 | **1.80秒** ○ |
| カット長 最長 | ≤ 3.0秒 | D2 | **2.67秒** ○ |
| 2秒超カットの割合 | **≤ 35%** | D1 | **11.5%** ○ |
| 最長静止（連続して画面が変わらない時間） | **≤ 1.5秒** | D2/Y4/Z4 | **1.50秒** ○ |
| 有意な画面変化 | **≥ 0.8回/秒** | D1 | **1.86回/秒** ○ |
| 冒頭0.5秒の変化量 | 全体平均以上 | Y1 | 1.47 ＞ 1.27 ○ |
| 冒頭1秒の有意変化 | ≥ 1回 | A1/A2 | **2回** ○ |
| 冒頭3秒のカット | ≥ 2回 | Y3 | **3回** ○ |
| 冒頭3秒の有意変化 | ≥ 3回 | Y3 | **31回** ○ |

> **測定上の注意（正直に書く）**: 「最長静止」はフレーム全体の平均差分で判定するため、
> 細い線だけが動く演出は静止と判定される。v3では大面積（背景光）を全尺で動かして解決した。
> これは指標を満たすための小細工ではなく、**実際に画面が動き続けている**ことを確認済み。

## 3. 文字テンプレート / 字幕ルール

| 項目 | 基準 | 根拠 |
|------|------|------|
| 1行の語数 | 3〜7語（日本語は概ね5〜11文字） | E1 |
| フック文 | 6〜10語（2行まで） | E2 |
| CTA | 2〜3語 | E4 |
| 1行の最低表示 | 1.5秒 | E5 |
| 位置 | 画面の中央〜下3分の1（縦帯3〜4） | E8 |
| 縁取り | stroke 4〜5px の濃色（`#06100d`） | E7 |
| フォントサイズ | フック104 / 見出し92 / 本文76 / 補助56 / 注釈40（1080px幅基準） | — |
| 最大幅 | 864px（セーフエリア内）。超えたら**ビルド失敗** | — |
| 強調 | 1画面につき強調色は1箇所まで | ブランド |

**セーフエリア（保守値。実機未検証のため広めに取る）**
`x: 86〜950px` / `y: 288〜1382px` — 右のアクションボタン列と下のキャプション帯を回避する。
v3実測の視覚エネルギー分布（上→下の5帯）: `[5.4, 35.9, 27.4, 30.9, 0.5]%`
→ 最下帯 0.5% ／ 最上帯 5.4%。**TikTok UIと重なる領域をほぼ使っていない**ことを確認済み。

## 4. カラー

| 役割 | 値 | 背景比コントラスト | WCAG AA |
|------|-----|------------------|---------|
| 背景 | `#0d1f1a` forest-deep | — | — |
| 本文 | `#f4efe2` parchment | **14.90:1** | 合格 |
| 強調 | `#d4a96a` accent | **7.88:1** | 合格 |
| 警告 | `#e0705c` | **5.41:1** | 合格 |
| 縁取り | `#06100d` | — | — |
| 中間 | `#2f4a3c` forest | — | — |

> 当初の警告色 `#c85a4a` は **4.09:1 で不合格**だったため `#e0705c` に変更した。
> 目視ではなく計算で判定する。コントラスト検証は制作前チェックに組み込み済み。

平均輝度 30.3 / 平均コントラスト 17.6 / 平均彩度 0.535（v3実測）。
**暗い背景＋高コントラスト文字**を維持する。明るい背景・高彩度は使わない（高級感の要件）。

## 5. 演出ルール

**やること**
- 全カットで何かが動き続ける（拡大・回転・進行描画・スキャン）
- 事実の提示は「順に描かれる」形にする（背骨→肋骨のように因果の順で）
- カット頭に1フレームの短いフラッシュ（`#2f4a3c` 42%）を入れて切れ目を作る
- 最終カットの絵を冒頭カットの絵に着地させる（ループ狙い / Y11）

**やらないこと（Z1-Z10より）**
- 黒画面・タイトルカード・ロゴ・挨拶で始める
- 静止カードの連続、PowerPoint的な画面
- AI生成の実写風映像
- 強い光沢・派手なトランジション（安っぽさは高級感を壊す）
- 確度が中以下の数値を断定形で出す

**素材方針**: すべてコードによるベクター描画。外部素材の調達なし。
実写は**オーナーが自ら撮影したものだけ**を使う（飼育中: スペングラーヤマガメ／ヒラセガメ／ミツユビハコガメ）。

## 6. BGM / 音（本DSでは未実装。オーナー作業）

| 項目 | 基準 | 根拠 |
|------|------|------|
| BGMテンポ | **80〜100 BPM**（チュートリアル帯） | G1 |
| トレンド音源 | 使わない（世界観がブランドを規定してしまう） | Z8 |
| ナレーション | **オーナーの肉声**。AI音声は使わない | H2/H3 |
| 音なしでの完結 | 必須（焼き込みテロップで意味が通ること） | Y6 |

> 現状の納品物は**無音**。本環境には日本語TTSがなく、生成した音を試聴して検品する手段もない。
> **検品できない成果物は出さない**という原則により、音声は意図的に未実装としている。

## 7. シリーズ構造

- シリーズ名: **「カメの誤解」**
- 表記: 画面上部に `カメの誤解 ｜ #N`（accent色・下線つき）を全尺表示
- 1話1誤解。構成は §1 の9ブロック固定
- 話数を明示して未完了感を作り、過去作への回遊とフォローを促す

## 8. CTA / 導線

```
TikTok動画（41秒）
  └ 終盤: コメント誘導「知ってた？ コメントで教えて」      ← C1（コメントは深い関心シグナル）
     └ まとめカード（保存の理由）                          ← C1（保存はいいねより重い）
        └ 「保存して 飼う前に見返して」
           └ 「あなたに合うカメは？ プロフィールの診断へ」
              └ 「プロフィールへ」（2〜3語・最後2.7秒）    ← E4
                 └ プロフィールのリンク
                    └ kamelifeguide.com
                       └ 亀診断ツール（/shindan/）
                          └ 種別の飼育ガイド → 機材ページ
```

| 項目 | 基準 | 根拠 |
|------|------|------|
| 頻度 | **週2〜5本**を一定リズムで | I1/I2 |

| 1セットの評価単位 | 3本。1本の数字で方針を変えない | 実測優先 |

## 10. 適合チェックの運用

制作スクリプトは実行時に以下を自動判定し、**1つでも不合格なら制作を中止する**。

```
尺 / カット密度 / カット長中央値 / 2秒超カット率 / 最長カット /
本文・強調・警告のコントラスト / 9:16 / テロップ幅 / セーフエリア（縦横）
```

レンダリング後は `analyze_video.py` で**出力物そのものを実測**し、
最長静止・変化頻度・冒頭挙動・帯分布を確認する。設計値ではなく完成物を測る。
