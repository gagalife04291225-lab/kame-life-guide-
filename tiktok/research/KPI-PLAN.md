# TikTok 効果測定計画 v1.0（データ分析部）

「勝てる理由を証明する」ためには、公開後に**証明できる形でデータが返ってくる**必要がある。
本計画はそのための最小構成である。

---

## 1. 公開前に潰さないといけない2件（未解決＝測定不能）

| # | 項目 | 状態 | これが未解決だと何が起きるか |
|---|------|------|----------------------------|
| 1 | TikTokプロフィールの外部リンク設置可否 | **未検証** | 導線が成立せず、サイト流入が0のままになる |
| 2 | GA4でTikTok流入を識別できるか | **未検証** | 流入があっても「TikTok経由」と分からず、効果を証明できない |

**この2件が未解決のまま公開すると、動画の良し悪しを検証できない。**
公開そのものより先に潰すべき項目として扱う。

### 2の具体手順（オーナー作業）

```
1. プロフィールのリンクに計測パラメータを付ける
   https://kamelifeguide.com/?utm_source=tiktok&utm_medium=social&utm_campaign=kame-gokai&utm_content=01

2. GA4 で以下を確認する
   - レポート > 集客 > トラフィック獲得 に「tiktok / social」が現れるか
   - 探索 で utm_content 別（動画ごと）に分解できるか

3. 診断ツール（/shindan/）到達をコンバージョンとして登録する
```

## 2. 固定KPI（動画1本あたり）

TikTok Analytics から取得する。**推測値は入れない。取得できなければ空欄のままにする。**

| # | 指標 | 取得元 | 目標（v3の設計根拠） |
|---|------|--------|---------------------|
| K1 | 3秒保持率 | TikTok Analytics | **70%以上**（下回れば冒頭2秒を作り直す） |
| K2 | 完走率 | TikTok Analytics | **50%以上**（41秒尺／基準ラインは70%） |
| K3 | 平均視聴時間 | TikTok Analytics | 20秒以上 |
| K4 | 保存数 / 再生数 | TikTok Analytics | 記録して基準値を作る（初回は目標を置かない） |
| K5 | シェア数 / 再生数 | TikTok Analytics | 同上 |
| K6 | コメント数 | TikTok Analytics | 同上 |
| K7 | プロフィール遷移率 | TikTok Analytics | 同上 |
| K8 | サイト流入数 | GA4 | 同上 |
| K9 | 診断ツール到達数 | GA4 | 同上 |
| K10 | 離脱ポイント（秒） | TikTok Analytics 保持率グラフ | 該当シーンを特定して次回改善に使う |

**初回は K4〜K9 に目標値を置かない。** 自分の基準値がまだ無いため、
外部の平均値を目標に据えると推測で判断することになる。3本揃った時点で基準値を確定する。

---

## 3. 判断ルール（1本の数字で方針を変えない）

| 観測 | 判断 |
|------|------|
| K1 < 60% | 冒頭2秒を作り直す（構成全体は変えない） |
| K1 ≥ 70% かつ K2 < 40% | 中盤が落ちている。K10で該当シーンを特定して1箇所だけ直す |
| K1・K2 とも良好で K7 が低い | CTAの位置と語数を見直す |
| 3本すべてで同じ傾向 | Design System を改訂する（v1.1） |
| 1本だけ突出/沈没 | **方針を変えない**（偶然を除外する） |
