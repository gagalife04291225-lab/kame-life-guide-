# 室内土飼育のコバエ対策 — 商品候補と掲載場所案（2026-09-08 監査・P2）

> 位置づけ: **記事新設はしない**。商品候補・掲載場所案・文言ルールまでを整理した作業メモ。
> 対象: 室内で床材（土・ヤシガラ等）を使う飼育で発生するコバエ（キノコバエ・ショウジョウバエ等）の成虫が **ケージ外へ飛び出したあと**の対策。

## 1. 役割分離（守る原則）

| 区分 | 内容 | 扱い |
|---|---|---|
| **根本対策** | ①床材の過湿を避ける ②食べ残しを早めに除去 ③排泄物を除去 ④腐敗した植物・有機物を残さない ⑤必要に応じて表土交換 ⑥通気確保 | 記事・ガイドの主文。商品導線なし |
| **補助** | 黄色粘着トラップ／UV 誘引式 電撃殺虫器（**ケージ外**） | optional 用品。「置けば湧かない」とは書かない |
| **禁止** | ケージ内使用の推奨／薬剤散布の安易な推奨／爬虫類への安全性未確認の殺虫剤／UV 殺虫器を必須用品扱い／「これで発生しなくなる」断定 | — |

## 2. UV 誘引式 電撃殺虫器（ユーザー実使用品）の判定

| 項目 | 判定 | 根拠 |
|---|---|---|
| 商品タイプ | **PRODUCT_TYPE_VERIFIED** | 365nm UV 誘引＋電撃格子の据え置き／吊り下げ型は amazon.co.jp に多数流通（`/dp/` URL を持つ掲載を複数確認） |
| ユーザー実使用品の Amazon identity | **NOT_FOUND_EXACT_MATCH** | 画像から ASIN・商品ページを推測しない方針。repo にも同種 ASIN は無い。型番・ブランドが手元にないため完全一致は確認できない |
| 用途 | **USE_CASE_PARTIAL** | 「ケージ外へ出た成虫の捕殺」は製品用途と一致。幼虫・発生源には無効（根本対策の代替ではない）。爬虫類ケージ近傍での安全性（UV・電撃・水濡れ）はメーカー記載なし |
| 追加可否 | **今回は追加しない** | 完全一致が確認できない ASIN を追加しない（ルール）。Owner が実使用品の ASIN を提示したら bare-ASIN 検索で identity を確認して追加する |

## 3. 商品データ設計（採用時）

- category は既存の **`accessory`** を使う（新カテゴリ `pest_control` は現時点で不要。accessory の意味が曖昧になった時点で再検討）
- キット非表示（`SK_CAT_ORDER` 外）。`need: 'optional'` 扱い
- `why` に必ず入れる文言: ケージ内には置かない／カメが触れない部屋側へ設置／水がかからない位置／幼虫・発生源対策の代替ではない／過湿・残餌・排泄物・腐敗有機物の管理が基本／optional 用品
