## D-01 — Short Video Gate のデッドロック

### 対象の規則

`.claude/rules/pm-conduct.md` §6 — 自前撮影なしの場合、正式APIキーまたはローカル配置で
取得した**商用利用可能で権利確認可能な HD 以上のカメ生体実写映像**が無ければ、
動画レンダリングを完成扱いにしない。

### 影響（実測）

素材監査（`experiments/kame-video-audit/AUDIT.md`・別リポジトリ）の結論:

- 台帳1,000スロット（Pexels / Pixabay）は **BLOCKED_API_KEY**。
  実測 — Pexels `HTTP 401 Missing API key` / Pixabay `HTTP 400 Invalid or missing API key`
- 実体297件を個別監査、95件を取得・全尺確認
- Mixkit のカメ動画22本は **全て Restricted License（personal use only）** で収益化不可
- **日本の飼育主要種**（クサガメ・ニホンイシガメ・ニオイガメ・チズガメ・ハコガメ類）で
  見どころがあり商用利用可の実写は**ほぼ存在しなかった**
- 商用可で強かったのはリクガメ（ケヅメ／サバクゴファー）とスライダー類に偏る

**自前撮影をしない方針**と合わせると、現状の素材調達のままでは
**動画は永久に完成扱いにできない。**

### 選択肢

| 案 | 内容 | 影響 |
|----|------|------|
| **A** | Pexels / Pixabay の無料APIキーを取得し repo secret へ登録 | 1,000スロットが開く。取得は Owner のアカウント作成が必要 |
| **B** | CC BY-SA 4.0 の継承条件を受け入れる | 監査TOP1（ケヅメが草を食べる超接写 1920×1012）とTOP3（幼体スライダーが水槽を泳ぐ 1920×1080）が使える。**完成動画も BY-SA で公開する義務**が生じる |
| **C** | 動画制作を一旦停止する | サイト本体の改善に集中する |
| **D** | §6 を緩める | **推奨しない**。緩めれば低品質な成果物が「完成」になる |

### 推奨

**A と B の併用**。A は素材の母数を増やし、B は**日本の飼育者に刺さる素材**を今すぐ使える。
D は採らない。§6 は今回 Owner が確定した規範であり、実現できないから緩めるのは
`pm-conduct.md` §4「結果を見て合格基準を下げない」に反する。

### 裁定が無い場合に止まること

**動画制作が止まる。** 現在の素材では §6 を満たせないため、
何を作っても「完成扱いにしない」で終わる。

## D-02 — PM 実務原則（§8）の承認

`.claude/rules/pm-conduct.md` §8 は **Claude Code 起案**（Owner の指示による）であり、
§1〜§7（Owner 確定）とは出所が異なる。§8 冒頭にその旨を明記済み。

7原則 — 8.1 Artifact First／8.2 反証可能な受入基準／8.3 PM 自身の数値にも出所／
8.4 STOP を成果として扱う／8.5 一度に1工程／8.6 自著の唯一の判定者にならない／
8.7 Owner 判断事項を作業報告に埋めない

### 選択肢

| 案 | 内容 |
|----|------|
| **A** | 全7原則を承認し、§1〜§7 と同格の規範に格上げする |
| **B** | 実務原則のまま維持する（上位規範と競合すれば §1〜§7 と憲法が優先） |
| **C** | 一部を削除・修正する |

### 推奨

**B**。§8 は本件1セッションの観察にもとづく。**格上げは複数案件で有効性を確認してからでよい。**
ただし **8.1（Artifact First）だけは A** を推す。今日の重大欠陥3件すべてを検出した唯一の手段であり、
根拠が実測である。

### 裁定が無い場合に止まること

止まらない。§8 は実務原則として機能する。
