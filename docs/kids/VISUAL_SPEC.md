## 3. 表示方式（重要）

### バナー方式を基本とする

背景は **各場面の冒頭に置く帯（バナー）**。
**本文・見出しの背後には画像を敷かない**。

理由: 本文が載る領域を全端末で合成すると元画像の約88%になり、
「明るい見せ場」と「文字の可読性」が両立しない（測定済み）。
バナー方式ならスクリム不要で、絵は制作されたままの明るさで表示され、
文字のコントラストは 9.38:1 のまま変わらない。

```
[ バナー画像 16:9 ]  ← ここだけが画像。文字なし・スクリムなし
[ 見出し・本文    ]  ← 緑ベタ地または不透明カード。画像なし
```

### BG-00 の扱い（未確定事項）

BG-00 を「バナーとして置く」か「ヒーロー背面に敷いて文字を重ねる」かは
**未確定**。BG-00 v3 は 16:9 バナー用として制作・検証済み。

重ねる方式を選ぶ場合の実測値:
- スクリムなし → 最悪 1.03:1（判読不能）
- スクリム 0.78 → 最悪 5.14:1（合格。ただし青空と海がほぼ消える）
- スマホでは左右 56% が切り落とされ、右半分の海景が画面外になる

BG-01〜BG-05 はいずれの場合もバナー方式で確定。**16:9 で制作してよい**。

## 4. aspect-ratio / object-fit

| 項目 | 値 |
|---|---|
| 制作比率 | **16:9**（全BG共通） |
| 推奨解像度 | 1920×1080 以上（最低 1600×900） |
| CSS aspect-ratio | `16 / 9` |
| object-fit | `cover` |
| object-position | `center` |
| PC時の高さ上限 | `max-height: 320px`（≥720px の画面） |

PCでは `max-height` により上下が各12.5%トリミングされる。
**主要な要素は縦 12.5%〜87.5% に収める**。

---

## 5. セーフエリア

| 範囲 | ルール |
|---|---|
| 上下 各12.5% | PCでトリミングされる。主題を置かない |
| 左右 各8% | 端末により切れる可能性。主題を置かない |
| 中央 | 制約なし。**低ディテールにする必要はない**（文字を載せないため） |

バナー方式では中央を空ける必要がない。情報量を落とさず描いてよい。

## 6. HTML文字と画像の関係

- **画像内に文字を一切入れない。** 文字はすべてHTML側で表示する
- ふりがなは HTML の `<ruby>` で表示し、ON/OFF 切替に対応する
- 画像に焼き込んだ文字は切替に対応できず、崩れるため禁止
- `alt=""`（装飾扱い）。内容はすべて本文にあるため読み上げを妨げない
- 本文サイズは変更しない（本文19px / 見出し21〜22px / ふりがな12.18px）
- **画像のために文字を小さくしない**

### さがしもの（学習の仕掛け）

各背景に本文と対応する発見要素を必ず1つ以上描き込む。
本文側に「この えの 中に ○○が いるよ。さがして みてね。」を添える。
BG-00 では 足あと・巣と卵・巣穴・3つの環境（海／岩場／森）が該当。

## 7. VISUAL MASTER ルール

**BG-00 v3 を VISUAL MASTER とする。** BG-01〜05 は以下に従う。

1. 比率は 16:9。全BG共通
2. 厚塗り寄り。輪郭線は描かない。葉は面で表現
3. やわらかい拡散光。強いハイライト・光条を作らない
4. 遠景を霞で白く飛ばして距離を出す
5. 明るさ L* 55〜60
6. 彩度 130〜140
7. 前景・中景・遠景の3層で奥行きを作る
8. 人工物は木と石のみ。必ず無地
9. 生きものの気配（足あと・巣・穴など）を必ず入れる
10. 主題は縦 12.5%〜87.5% に収める
11. 画像内に文字を入れない
12. キャラクターを背景に描き込まない

## 8. 禁止事項

- 画像内に文字・数字を入れること（看板を描く場合は面を無地にする）
- ガイドキャラクターを背景に焼き込むこと
- 人物を描くこと
- 既存の作品・キャラクター・意匠を模倣すること
- 生態的に成立しない組み合わせ（リクガメを泳がせる、森の種を水中に置く等）
- CITES I・特定外来生物・天然記念物にあたる種を主役として大きく描くこと
- アカミミガメを主役として大きく描くこと
- 血・けが・死・過度に悲しい表現
- 灯台・電線・金属・舗装路・ランタンなどの人工物
- 商品・購入・ブランドロゴを想起させる要素
