## 0. 本レポートの読み方と検証ステータス（先に読んでください）

### 0-1. 検証方法と、その限界

本調査は Web 検索により実施しました。**ただし、実行環境のネットワーク egress ポリシーにより、公式ページの直接取得（WebFetch）が下記ドメインを含めほぼ全ての商用ドメインでブロックされました。**

- ブロックされた例: `pixta.jp` / `faq.snapmart.jp` / `www.canva.com` / `coconala-support.zendesk.com` / `funnel-inc.jp` / `www.kokusen.go.jp`

したがって「公式サイトを直接開いて数値を目視確認した」項目は**ゼロ**です。実際に行えたのは、検索エンジンが公式ページ（国民生活センター発表、PIXTAガイド、ココナラ公式サポート、TikTok for Business ヘルプ、Canva Japan の PR TIMES リリース、App Store 掲載情報など）を索引した本文の抽出と、複数媒体のクロスチェックです。

**この差は重要なので、各項目に確信度を付けます。**

| ラベル | 意味 |
|---|---|
| **高** | 公的機関・運営元公式ページ由来の記述が検索結果本文として確認でき、複数媒体と矛盾しない |
| **中** | 業界メディア・複数の独立した媒体で一致するが、運営元公式の原文を直接確認できていない |
| **低** | 個人ブログ・note・アフィリエイト記事のみが出典。数値は「そう主張されている」以上のことは言えない |

**実際の申込・契約前には、必ず運営元の公式ページで最新の条件・手数料・フォロワー要件をご自身で確認してください。**特にフォロワー要件と手数料率は改定が頻繁です。

### 0-2. 除外した情報

以下は「根拠なし」または「危険」と判断し、候補から除外、もしくは危険性を明記しています。

- 「簡単に月30万円」「スマホをタップするだけで日給2万円」等、労働量と報酬の対応が説明できないもの
- LINE誘導 → 高額スクール / 情報商材 / 投資 / マルチ商法への導線が主目的のもの
- AI で生成した「偽の成功実績スクショ」を根拠に使っているもの

**国民生活センターは2026年5月19日に「簡単なタスクで稼げるとうたう副業トラブルに注意！」を発表しています。**「いいねを押すだけ」「スクショを撮るだけ」「動画を見るだけ」型の広告が入口で、最初に少額の報酬を渡して信用させ、その後「グループの連帯責任」等の名目で高額を要求する、スマホを遠隔操作させて消費者金融から借金させる、といった手口が報告されています。被害は20〜30代に集中。相談先は消費者ホットライン **188**。（確信度: 高）

### 0-3. 2026年に起きた「前提が変わった」4つの構造変化

調査中に判明した、2026年時点で必ず織り込むべき変化です。まとめ記事の多くはこれを反映していません。

| # | 変化 | 意味 | 確信度 |
|---|---|---|---|
| 1 | **TikTok Shop 日本が本格離陸**。2025年7月開始、半年で累計流通額 約155億円、2025年12月は単月約60億円規模。2026年末には年間約1,283億円の予測（studio15 市場白書）。**購買の中心は35〜54歳の女性**、GMVの約7割が動画/ライブ起点 | 「女性が売り、女性が買う」経済圏が国内に成立した。ここが2026年最大の新市場 | 中〜高 |
| 2 | **PIXTA が生成AI作品の取り扱いを終了**（2026年4月20日 投稿停止 / 5月22日 販売停止）。一方 Adobe Stock は「Generative AI」開示を条件に販売可・支払率33% | 「AI画像を国内ストックで量産して売る」は主要導線が1本閉じた。逆風 | 中〜高 |
| 3 | **YouTube が AI量産・低付加価値ショートを収益化対象外に**（2026年1〜2月にかけて運用強化）。BGM＋字幕のみの顔出しなし量産動画、同一フォーマットの反復が対象 | 「AIで自動生成ショートを量産して広告収益」は成立しにくくなった。逆風 | 中 |
| 4 | **Instagram のギフト機能のフォロワー要件が5,000人→500人に緩和**。リールへのアフィリエイトリンク付与も2026年4月にInstagram側から発表 | 小規模アカウントの収益化ハードルが下がった。追い風 | 中 |

**結論の方向性**: 2026年は「**AIで作ったものをそのまま売る**」は各プラットフォームが締めており逆風。「**AIで作業時間を圧縮して、人間の判断・実体験・納品責任を売る**」が順風です。これが本レポートの評価軸の背骨になっています。

### 1位: ショート動画編集代行（ココナラ＋クラウドワークス）

**選んだ理由**

- **実案件が今この瞬間に実在する**。ココナラに「リール2本3,000円」「1本3,500円」の出品が現に存在し、購入者がいる市場だと確認できた。「稼げるらしい」ではなく「取引されている」
- **フォロワーゼロ・実績ゼロ・顔出しなしで成立する**唯一に近い現金化ルート。フォロワー1,000人の壁を待つ必要がない
- CapCut無料版で完結し、初期費用が本当に0円
- AIの恩恵が最も大きい（自動字幕・読み上げ・背景除去）ため、初心者でもプロに近い速度で納品できる
- **積み上がる**。編集ができるとUGC制作にもSNS運用代行にも横展開でき、単価を上げていける（Dランキング1位・2位への直通路）

**今日やること（3時間）**

1. CapCutをインストールし、無料版のまま「自動字幕」「テキスト読み上げ」「背景除去」の3機能だけを触る（60分）
2. 自分で撮った素材（食事・散歩・部屋の掃除、何でもいい）で**15〜30秒のリールを3本**作る。テーマは意図的にバラす：①商品紹介風 ②How to風 ③日常Vlog風（90分）

> 価格を1,500円にしないこと。安すぎる出品は「初心者だから安い」と読まれます。修正回数の上限明記は絶対に外さないでください。ここを空欄にすると無限修正で消耗します。

| 1週目 | サンプル5本＋出品完了＋10件応募 | 上記 |
| 2週目 | **初受注1件（2,500円）** | 応募を週15件に増やす。ココナラは「初回限定1,500円」の期間限定枠を1つだけ作り、レビュー1件目を取りに行く |
| 3週目 | 累計3件（約7,500円） | レビューが1件付いた時点で通常価格に戻す。納品の速さ（依頼から48時間）を売りにする |
| 4週目 | **累計5〜8件、月1.5万〜2万円** | 受注済みクライアントに「月4本まとめて8,000円」の継続プランを提案。単発から継続へ切り替える |

30日後の現実的な着地は**1万〜2万円**。ここで「継続契約1件」が取れていれば、翌月からは営業ゼロで同額が入ります。

### 2位: 楽天ROOM ＋ Instagram/Threads（保険＆入口）

**選んだ理由**

- 審査・要件・費用がすべてゼロ。**「30日以内に1円も入らない」という最悪ケースを潰すための保険**として置きます
- 1位の作業と競合しない（1日15分で回る）
- 商品を選び、写真を撮り、紹介文を書くという行為が、そのままUGC制作・アフィリエイトの基礎訓練になる
- 楽天キャッシュでの受取なので「現金」ではない点は正直に減点しています。だから1位ではなく2位です

**今日やること（1時間）**

1. 楽天ROOMを開設し、プロフィールに「何の人か」を一行で書く（例:「3歳児と暮らす狭い賃貸の収納」）
2. **テーマを1つに絞る**。「なんでも紹介」は絶対に売れません。自分が過去1年で実際に買って良かったものだけを10点、ROOMに登録する
3. 各商品に「なぜ買ったか・何が良かったか・誰に向くか」を3行で書く

**7日間の行動**

- 毎日3商品ずつ追加（7日で累計31商品）。すべて**実際に使ったもの、または本気で欲しくて調べたもの**に限定する
- 4日目からThreadsを開設し、同じテーマで1日1投稿。ROOMのリンクはプロフィールに置く
- 7日目に、保存・クリックが多かった商品ジャンルを確認し、以降そこに寄せる

**30日間の収益化ルート**

| 週 | 目標 |
|---|---|
| 1週目 | 商品30点、テーマ確定 |
| 2週目 | 商品50点、Threads毎日投稿、**初報酬（数十円）** |
| 3週目 | 売れた商品の傾向を分析し、同カテゴリを厚くする |
| 4週目 | **月500〜2,000円**。金額は小さいが「自分の紹介で人が買う」という再現可能なデータが取れる |

30日後の金額は小さいです。**この2位の価値は金額ではなく、「どの商品を、どう紹介すると人が動くか」の実データ**にあります。それが3位とTikTok Shopの原資になります。

### 3位: UGCクリエイター（30日目に仕込み、2ヶ月目に刈り取る）

**選んだ理由**

- **単価が本命**。個人受注で5,000〜3万円、企業のUGC動画発注予算は1本5万〜20万円。30日で最初の収益を作る種目としては遅いが、**60〜90日で月5万円に届く最短路**
- **フォロワーが一切要らない**。ブランドが見るのは素材の質だけ。これは女性・主婦にとって決定的に有利です（フォロワーを増やす数ヶ月をスキップできる）
- 1位で身につけた編集スキルがそのまま武器になる。1位→3位は同じ道の延長線上にあります
- 2026年時点で「素人感のある広告素材」の需要が実際に伸びており、Indeedに求人が実在する

**今日やること（2時間）**

1. **自宅にある商品を3つ選ぶ**（化粧品・洗剤・食品など、広告が実際に打たれているカテゴリ）
2. 各商品について、**3パターンの型**で15秒動画を1本ずつ作る:
   - **開封型**（手元だけ・BGM・字幕）
   - **問題解決型**（「〇〇で困ってた」→「これに変えた」）
   - **使用シーン型**（生活の中で使っている様子）
3. AIに「この商品の広告訴求ポイントを10個」を出させ、字幕に落とし込む

**7日間の行動**

| 日 | やること |
|---|---|
| 1 | 上記3本を制作 |
| 2〜3 | さらに2商品分（計9本）制作。**ポートフォリオは最低5〜10本必要**というのが2026年の実態 |
| 4 | 9本をまとめたポートフォリオをGoogleドライブかInstagramの専用アカウントに整理。**顔出しなしで統一** |
| 5 | クラウドワークス・ランサーズで「UGC」「動画素材」「広告用動画」「縦型動画」を検索し、募集要項を精読。単価と納品形式の相場を把握する |
| 6 | ココナラに「UGC動画素材 1本8,000円（3パターン込み）」で出品。1位の編集代行とは別サービスとして立てる |
| 7 | 実際に自分が使っている商品のメーカー（中小・D2Cブランドを狙う。大手は窓口が閉じている）に、Instagram DMまたは問い合わせフォームから**ポートフォリオ付きで3社に打診** |

**30日間の収益化ルート**

| 週 | 目標 |
|---|---|
| 1週目 | ポートフォリオ9本完成、ココナラ出品、3社打診 |
| 2週目 | 打診を週5社に。並行してクラウドソーシングのUGC案件に週5件応募 |
| 3週目 | **初受注（8,000〜1.5万円）**。この段階では受注できていなくても異常ではありません |
| 4週目 | 受注1〜2件で**8,000〜3万円**。受注ゼロでもポートフォリオが15本に育っていれば計画通り |
| 2ヶ月目以降 | 単価を1.2万円に上げ、月4本で**月5万円**が射程に入る |

**打診の文面で絶対にやってはいけないこと**: 「PRさせてください」と書くこと。これはギフティング（現物）の依頼になり、現金になりません。**「御社の広告用素材を制作します。サンプルはこちらです」**と、納品業者として名乗ってください。ここが候補06（ギフティング）と候補07（UGC）を分ける決定的な一線です。

---

### なぜ TikTok Shop アフィリエイトを1〜3位に入れなかったか

市場としては本レポート中で最も伸びており（2026年末 年間1,283億円予測）、購買層も35〜54歳女性と完全に一致しています。**中長期では最有力です**（Dランキング3位）。

外した理由はひとつだけです。**クリエイター側の参加にフォロワー1,000人前後が必要**とされており、**「今日スマホ1台、30日以内に最初の収益」という条件と噛み合いません**。ゼロからフォロワー1,000人は、順調でも1〜3ヶ月かかります。

したがって推奨する順序はこうです。

> **1位（編集代行）で現金と編集スキルを作る → 2位（楽天ROOM）で「売れる紹介の型」を掴む → 3位（UGC）で単価を上げる → その過程で自然に増えたフォロワーが1,000人を超えたら TikTok Shop アフィリエイトを起動する**

30日ではなく90日で設計すると、この順番が最も無駄がありません。

## 5. 危険な型のチェックリスト（保存推奨）

以下に1つでも当てはまるものは、金額の大小にかかわらず手を出さないでください。

| # | 危険サイン | 理由 |
|---|---|---|
| 1 | 「いいねを押すだけ」「動画を見るだけ」「スクショを撮るだけ」 | 国民生活センターが2026年5月19日に名指しで注意喚起した手口そのもの |
| 2 | 最初に少額（数百〜数千円）の報酬が実際に振り込まれ、その後に入金を求められる | 典型的な信用構築型の詐欺。**最初に払ってくれること自体が手口の一部** |
| 3 | 「グループの連帯責任」「タスクを完了しないと全員が損をする」 | 心理的圧力で追加入金させる定型句 |
| 4 | 遠隔操作アプリのインストールを求められる | 消費者金融から借金させられた被害が報告されている |
| 5 | Instagram DM → LINE → 個別通話 → 高額スクール（数十万円） | 導線自体は正当なマーケティングでも使われるが、**金額提示が通話まで出てこない**場合は危険 |
| 6 | 収益の証拠がスクショのみ | AIで簡単に偽造できる。**確定申告書や取引明細でなければ証拠価値はない** |
| 7 | 「誰でも」「必ず」「絶対」「初月から」 | 特定商取引法・景品表示法の観点でも問題があり、まともな事業者は書かない |

**相談先: 消費者ホットライン 188（いやや！）**

また、正規の副業でも以下は必ず守ってください。

- **ステマ規制（景品表示法）**: 企業から商品や報酬を受けた投稿には「PR」「提供」を必ず明示する。ギフティング案件も対象です
- **薬機法**: 化粧品・健康食品で「治る」「痩せる」等の効能を断定しない
- **確定申告**: 給与所得者は副業所得20万円超で申告が必要。**KDPは源泉徴収されない**、**ギフティングの現物も経済的利益になりうる**点に注意
- **本業の就業規則**: 副業可否を必ず確認

## 6. まとめ（この調査から出た結論）

1. **2026年のスマホ副業の主戦場は「AIで作ったものを売る」から「AIで時間を圧縮して人間の判断を売る」に移った。** PIXTAのAI取扱終了、YouTubeのAI量産動画の収益化除外という2つの一次変化がそれを示しています
2. **フォロワー数は、もはや必須条件ではない。** UGCクリエイター、編集代行、SNS運用代行、ココナラ、デジタル商品販売は、フォロワーゼロで現金化できます。「まずフォロワーを増やす」は2026年においては遠回りです
3. **最も速く現金になるのは「編集代行」、最も伸びるのは「UGC」、最も市場が熱いのは「TikTok Shop」。** この3つは同じ道の上にあり、順番に踏むのが最短です
4. **ギフティングは収入ではない。** ここを混同させる記事が非常に多く、これが「頑張っているのに口座残高が増えない」の最大の原因です
5. **本レポートの数値は、環境制約により公式ページの直接確認ができていない。** 契約・申込の前に必ず公式で最新条件を確認してください
