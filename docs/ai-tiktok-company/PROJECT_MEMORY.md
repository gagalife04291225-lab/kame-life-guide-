## 5-2. 標準運用ルール（実行方式 / 恒久・オーナー承認 2026-07-29）

> 設計（Phase 0/0.5/1/1.5/1.6）は不変更。**実行方式のみ**を KAME LIFE GUIDE / DCS と同じ方式に統一する。詳細は 専用リポ `ai-tiktok-company/docs/OPERATIONS.md`。

- **標準運用 = Claude Code をローカル(セッション)で実行 → GitHub へ commit → 必要に応じて push → 結果を報告**。GitHub は「記録・状態の保管場所」。
- **GitHub Actions による自動実行を前提にしない**。特に **GitHub Actions から Anthropic API を常時呼び出す構成は採用しない**（追加課金を前提にしない）。AI社員の実行は Claude Code の通常運用で行う。
- **GitHub 認証ルール**：GitHub 権限が不要な作業では PAT / API キーを要求しない。**GitHub 権限が必要な作業になった時だけ「PATが必要です」と理由を明確に報告**し、提供まで権限要処理は実施しない。実行できない前提条件があれば最初に報告する。権限不要な作業はそのまま継続する。
- **PAT が必要な代表例**：新規リポジトリ作成 / GitHub Secrets 変更 / GitHub Settings 変更 / GitHub App 権限で不可の操作。※本リモート環境では通常の commit/push は事前設定プロキシ経由で成功するため PAT 不要。PAT が要るのは「現在の権限で 403 になる操作」。
- **PAT 運用**：受領後は必要な作業のみ実施 → 完了後に必ず「PATを revoke してください」と案内。使い回し禁止。
- 実装の Actions ワークフロー(00〜40)は非標準として `optional/actions-mode/` に退避（採用しない代替案・参考保管）。`99-bootstrap-labels`(GITHUB_TOKENのみ) のみ setup 用途で保持。
- **副次効果**：標準運用ではパイプラインが Actions/Anthropic API に依存しないため、`ANTHROPIC_API_KEY` の Secret 登録は不要。
