# 森林・ハコガメ群18件の用品条件照合（2026-11-13）

既調査44件は対象外。18件すべて判定済み。ただし属群/自然史のみに留まる項目を、種固有の用品適合確認済みとは数えない。共有species.jsは変更していない。

## 判定
### wood-turtle
- 状態: conditions_reviewed_with_scope_limits
- 条件案: 水中だけでなく、歩ける陸地と日陰も確保する。
- 条件案: 水場から陸へ移れる足場を作り、水温と日陰の温度を別々に見る。
- 適用範囲: 冷却の要否は設置環境の実測で判断。深さ2ftや屋外飼育を一律条件にしない。
- 資料: https://www.austinsturtlepage.com/Care/cs-nawood.htm

### hirase-turtle
- 状態: conditions_reviewed_with_scope_limits
- 条件案: 床材と隠れ家を置ける陸地を中心に組む。
- 条件案: 水場と乾いた休み場所を用意し、登って外へ出られないか確認する。
- 適用範囲: 種自然史とobstiの飼育実例。obstiの温度や湿度をヒラセ全個体へ転用しない。
- 資料: https://www.cuora.org/cuora-mouhotii / https://theturtleroom.org/blog/2014/04/25/cuora-mouhotii-obsti-acclimation-care/

### obsti-hirase-turtle
- 状態: conditions_reviewed_with_scope_limits
- 条件案: 潜れる床材と暗い隠れ家を用意する。
- 条件案: 体を浸せる水場は出入りしやすくし、壁際や家具からの脱走にも気をつける。
- 適用範囲: 4頭の飼育例に基づく。成体用容器寸法や灯具能力の保証ではない。
- 資料: https://theturtleroom.org/blog/2014/04/25/cuora-mouhotii-obsti-acclimation-care/ / https://www.cuora.org/cuora-mouhotii

### painted-wood-turtle

- 適用範囲: masterはR.pulcherrima種全体。一般名だけでmanni用数値を採用しない。

### annulated-wood-turtle

## 具体的な不整合
- 通常と全表示でforest→tortoise_dry_smallへ変わるヒラセ/obsti/ニカラグア/ソノラ/ゲレーロは導線不一致。
- Cyclemysはforestキーとsemi_aquatic_mediumページの不一致。水場を欠く陸用セットでは完結しない。
- painted-wood-turtle masterはR.pulcherrima種全体。manni固有条件として扱わない。
- desert-box-turtle和名ミナミニシキに対してmasterはT.ornataで亜種未記載。
- 中国セマルmasterはC.flavomarginata種全体。sinensisの学名採用は分類見解を明示して別途判断。
- 資料に温湿度などが載ることと用品の能力・適合確認は別。全18件にproduct_fit_verified=falseを保持。
