# KAME LIFE GUIDE — TikTok 25秒 承認台本「カメふしぎ島」

更新日: 2026-08-14
ステータス: 承認済み（亀好きさん）
関連: `red-eared-slider-family-concept.md`（画像コンセプト・2026-08-12 承認）

## 目的

「子どもがカメを連れて帰ってきた」という実際に起きる出来事を入口に、
親子でカメふしぎ島を使って調べる流れを25秒で見せ、
カメライフガイドへの検索行動につなげる。

## 制作メモ

- 編集は CapCut 等で行う。動画ファイルはこのリポジトリに置かない
- テロップは画像内に焼き込まず、編集ソフト側で載せる
  （写真は上部に余白を確保済み）
- ナレーションは全編ボイスオーバー。画面には出さない
- 「カメライフガイド 検索してみてね！」は最後に大きく2回目を出す
