### 寄り（ズーム）の指定方法

`transform: scale()` は**要素の中心**を基準に拡大する。`focus`（`object-position`）は
切り抜き位置を決めるだけで、寄り先は決められない。寄り先は `origin`（`transform-origin`）で指定する。

カット1はカメに寄って始まる必要があるため、`origin: '72% 84%'` を実測して指定している
（カバー切り抜き後の画面内でカメが来る位置）。他のカットは中心基準で問題ない。

未配置のカットがあっても「PHOTO 未配置」のプレースホルダーで描かれ、書き出しは通る。

### 監査の指摘を反映した点（CTA）

`red-eared-slider-family-video-evaluation.md` の監査は、
**「『カメライフガイド』で検索」＋URLテキストの CTA では TikTok から外部に出られず、
GA4 の `utm_source=tiktok` に流入が計上されない**と結論している
（TikTok で唯一クリックできる経路はプロフィールの bio リンク）。

ただし**この監査は「bio リンクが使える」ことを前提にしている。その前提自体が未確認**。

TikTok でタップできるのはプロフィールのウェブサイト欄だけで、動画内の文字・
キャプション・コメントの URL はどれもタップできない。ウェブサイト欄が使えるかは
アカウント種別による（ビジネスアカウントなら可、という記述で各社一致。個人アカウントは
「1,000フォロワー必要」と「2024年に撤廃済み」が混在し、公式の一次情報にたどり着けなかった）。

欄が無い場合「プロフィールのリンクから」は**嘘になる**ため、現在は常に真である
**「「カメライフガイド」で けんさく」** を採用している（判断順序 正確性 ＞ … ＞ 再生数）。

**確認方法（1分）**: TikTokアプリ → プロフィール → プロフィールを編集 → 「ウェブサイト」欄の有無。

欄があると確認できたら、CTA を「プロフィールのリンクから 👆」に戻し、bio に
UTM 付き URL を入れる。そうしないと動画が当たっても KPI 上は 0 に見える。

```
https://kamelifeguide.com/kids/?utm_source=tiktok&utm_medium=social&utm_campaign=fushigijima
```

## 事実確認と注意点

### アカミミガメの法的扱い（重要）

この動画は「川で拾ってきたアカミミガメを家で飼う」という筋書きになっている。

- **CLAIM**: 拾ってきたアカミミガメを家庭で飼うことは可能。
- **SOURCE**: アカミミガメは 2023年6月1日から外来生物法の「条件付特定外来生物」。
  一般家庭での飼育・運搬は許可不要。一方で **販売・購入・頒布（有償譲渡）と、野外への放出は禁止**。
- **CONFIDENCE**: 高（制度の骨格）／ 中（個別ケースの運用）
- **DOUBT**: 「拾ってくる」描写が「また川に戻せばいい」と受け取られると、**放出＝違法行為**を誘発しかねない。
- **RECONCILE**: 台本上「川に返す」描写・示唆は入れない（現状の台本には無い）。
  最後の導線が `kids/` に向いているので、`kids/yakusoku.html`（さいごまでお世話をする）と
  `kids/chuui.html`（やってはいけません）が受け皿になる。
  コメント欄で「逃がせばいい」という反応が出た場合は、放出が禁止であることを明示して返す。

### 島のイラストを本編から外した（2026-08-14 亀好きさん指示）

当初 11.1〜17.3秒は `assets/kids/` の島のイラスト4枚（島の全景・もり・みずべ・かわいた）を
使っていたが、**親子写真の流れの中に突然イラストが挟まって何を見せられているのか分からない**
という指摘を受け、全部を親子写真に差し替えた。あわせて文言を「親子で」→「一緒に」に変更した。

- 本編（0〜22秒）は `photos/` の親子写真5枚だけで構成する。同じ写真を寄り先を変えて使い回す
- 4カットは 顔 → スマホ → カメ → 顔 の順にして、見る対象が変わっていくようにした
- **エンドカード（22〜25秒）だけは島の絵を残している。** 画面に「カメふしぎ島」と
  書いてあるので何の絵か迷いようがなく、動画中で唯一「行き先」を見せる場所だから。
  ここも親子写真にする場合は `c6` の `src` を差し替えるだけでよい

**トレードオフ（正直に書く）**: この構成だと、視聴者はカメふしぎ島が
どんな見た目のサイトなのかを最後の3秒しか見ない。行き先の魅力を見せる量は減っている。

### テロップとサイト構成のズレ（要判断）

11–17秒のテロップ「見る 👀 / 探す 🔍 / くらべる 🐢 / 考える 💡」は、
**カメふしぎ島に実在するエリア名ではない**。実際の島は次の8ヶ所。

`いりぐち / ふしぎ / もり / みずべ / かわいた / やくそく / ちゅうい / クイズ`

- そのままでよい場合: 動きを表す言葉としてリズム重視で残す（現在の実装）。
- サイトと一致させたい場合: `storyboard.html` の `c4a`〜`c4d` のテロップを
  `カメの ふしぎ 🐢 / しめった もり 🌿 / みずべ 💧 / かわいた ばしょ ☀️` に差し替える。
  背景画像はすでにこの順（島 → もり → みずべ → かわいた）で並べてあるので、文言だけ変えれば整合する。

亀好きさんの判断待ち。判断が出るまでは台本どおり（前者）で実装している。
