### 寄り（ズーム）の指定方法

`transform: scale()` は**要素の中心**を基準に拡大する。`focus`（`object-position`）は
切り抜き位置を決めるだけで、寄り先は決められない。寄り先は `origin`（`transform-origin`）で指定する。

カット1はカメに寄って始まる必要があるため、`origin: '72% 84%'` を実測して指定している
（カバー切り抜き後の画面内でカメが来る位置）。他のカットは中心基準で問題ない。

未配置のカットがあっても「PHOTO 未配置」のプレースホルダーで描かれ、書き出しは通る。

## 事実確認と注意点

### アカミミガメの法的扱い（重要）

この動画は「川で拾ってきたアカミミガメを家で飼う」という筋書きになっている。

- **CLAIM**: 拾ってきたアカミミガメを家庭で飼うことは可能。
- **SOURCE**: アカミミガメは 2023年6月1日から外来生物法の「条件付特定外来生物」。
  一般家庭での飼育・運搬は許可不要。一方で **販売・購入・頒布（有償譲渡）と、野外への放出は禁止**。
- **CONFIDENCE**: 高（制度の骨格）／ 中（個別ケースの運用）
- **DOUBT**: 「拾ってくる」描写が「また川に戻せばいい」と受け取られると、**放出＝違法行為**を誘発しかねない。
- **RECONCILE**: 台本上「川に返す」描写・示唆は入れない（現状の台本には無い）。
  最後の導線が `kids/` に向いているので、`kids/yakusoku.html`（さいごまでお世話をする）と
  `kids/chuui.html`（やってはいけません）が受け皿になる。
  コメント欄で「逃がせばいい」という反応が出た場合は、放出が禁止であることを明示して返す。

### テロップとサイト構成のズレ（要判断）

11–17秒のテロップ「見る 👀 / 探す 🔍 / くらべる 🐢 / 考える 💡」は、
**カメふしぎ島に実在するエリア名ではない**。実際の島は次の8ヶ所。

`いりぐち / ふしぎ / もり / みずべ / かわいた / やくそく / ちゅうい / クイズ`

- そのままでよい場合: 動きを表す言葉としてリズム重視で残す（現在の実装）。
- サイトと一致させたい場合: `storyboard.html` の `c4a`〜`c4d` のテロップを
  `カメの ふしぎ 🐢 / しめった もり 🌿 / みずべ 💧 / かわいた ばしょ ☀️` に差し替える。
  背景画像はすでにこの順（島 → もり → みずべ → かわいた）で並べてあるので、文言だけ変えれば整合する。

亀好きさんの判断待ち。判断が出るまでは台本どおり（前者）で実装している。
