| ファイル名 | 内容 | 使用秒 |
|---|---|---|
| `01-turtle-case.jpg` | 透明ケースのカメが大きく写るカット | 0.0–3.4 |
| `02-parent-child-phone.jpg` | 親子が同じスマホをのぞき込む | 3.2–7.3 |
| `03-searching.jpg` | 母が真剣に検索している | 7.1–11.3 |
| `05-family-smile.jpg` | 親子が笑顔でスマホを見る | 17.1–22.2 |

生成条件は `../../red-eared-slider-family-concept.md`（承認済みコンセプト）に従う。
`.jpg` 以外を使う場合は `../storyboard.html` の `CUTS` 内 `src` も合わせて直すこと。
