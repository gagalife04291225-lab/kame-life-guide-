Care Library

選んだ後も、飼育で迷わせない。

水槽・床材・温度・食事。飼い始めてから必要になる知識を、飼育スタイル別に整理しています。

Care Module 01 🐢
はじめての1頭、どう選ぶ？

難易度・費用・サイズの三軸で、はじめて飼う方が後悔しにくい種をランキング形式で解説。

はじめての方向け選び方を読む Care Module 02 🔬
スペースが限られている？

30〜45cm水槽から飼える最大15cm以下の小型種を厳選。省スペース派に最適な3種を比較。

小型種3選を見る Care Module 03 🌿
室内の臭いが心配？

管理次第で臭いを抑えられる種と方法を解説。陸棲なら水の問題ごと解消できます。

臭い対策ガイドを読む Care Module 04 📏
飼育用品、サイズで失敗したくない？

うちの子の甲長から「今使える／もう使えない／次に買う」を逆引き。実飼育者の失敗事例つき。安全判定を購入リンクより先に。

KID（甲長逆引きDB）を見る Care Module 05 🧒
お子さんが亀に興味を持った？

お子さん自身が読める「カメふしぎ島」。全漢字ふりがな付きの8ページで、しめった森・水辺・かわいた場所をめぐりながら、カメの体と暮らしを見くらべます。カメと暮らす約束、やってはいけないこと、最後はカメクイズ。商品リンクは一切ありません。
